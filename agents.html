What goes where?

JEV: BOUNDED JUDGMENTS
  • Which tool is relevant?
  • Does this result answer the question?
  • Does the proposed reply contradict the record?
  • Should the system seek clarification?
THE REST OF THE SYSTEM
  • LLM: make a plan and write the response.
  • Tools: retrieve authoritative facts.
  • Code: check access, limits and consent.
  • Runtime: retry, log and verify tool outcomes.

Independent judgments over one observation can share a request. A judgment that depends on the result of a tool call must wait for that result. Parallel answers do not make an entire agent workflow parallel.

Four kinds of judgment inside an agent

Tool selection

Retrieve plausible tools, compare their descriptions against the goal, then choose from the permitted tools. Track tool-selection accuracy and completed tasks.

Search and RAG

Judge which retrieved passages support the answer. Feed the useful evidence to the writing model. Track answer quality, recall and tokens saved.

Context selection

Keep important original messages and prune stale results. Pin critical instructions and recent context in code. Track facts lost, not just tokens removed.

Run review

Check whether the agent’s success claim matches the tool results. Escalate uncertain runs. Track silent failures caught and false alarms.

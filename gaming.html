DEEP DIVE

Gaming & real-time systems

Games make the System One idea intuitive: at 10 decisions per second, generating prose is mostly wasted work. The useful output is usually what should I do now?

Real TypeSafe demo: Jev plays Doom from structured textual game state at roughly 10 queries/second. TypeSafe explicitly notes that it is not image-based yet and that a hand-built Doom bot could play better; the point is reactive instruction-following over changing state.

A Jev-driven game loop

every 100ms:
  state = {
    health, ammo, enemies, positions,
    visible_items, objective, recent_events
  }

  d = jev.ask(state, {
    action: Choice([MOVE, ATTACK, DODGE, PICK_UP, RETREAT]),
    target: Choice(visible_targets),
    danger: Score([LOW, MEDIUM, HIGH, CRITICAL]),
    objective_met: Noul("Has the current objective been achieved?")
  })

  game.execute(d.action, d.target)

Why gaming is a useful analogy

NPC behavior

Give an NPC personality + world state and choose from legal actions. Code still enforces physics, inventory and game rules.

Choice([help, trade, flee, fight, investigate])

Dynamic difficulty

Judge how challenged or frustrated the player appears from gameplay state, then adjust within designer-defined bounds.

Score([bored, comfortable, stretched, overwhelmed])

Moderation

Classify chat or user-generated content with several independent semantic booleans instead of asking a chatbot to write a moderation essay.

Noul(toxic), Noul(threat), Noul(spam)

Matchmaking & recommendations

Retrieve candidate games/players/matches, judge fit against intent or play style, then sort.

Score(match_quality)

Live director

A game director can choose which event should happen next from a legal menu based on pacing and player state.

Choice([quiet, encounter, reward, story_beat])

Simulation agents

At high decision volume, low-latency bounded judgments can make populations of agents more feasible than repeated generative calls.

Wikiracing: the high-cardinality lesson

TypeSafe also demonstrates Jev navigating Wikipedia by choosing links toward a target page. A page can contain hundreds or thousands of links. Jev's current Choice cardinality is up to 255, so TypeSafe says larger action sets use a two-stage system: independently score/narrow candidates, then make an explicit Choice.

# General pattern for huge action spaces
candidates = environment.available_actions()       # maybe 2,000
scored = parallel_score(candidates, "moves us toward goal")
shortlist = top(scored, 100)
action = Choice(shortlist)

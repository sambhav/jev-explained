ABSOLUTE

Is this document useful?

Score each candidate independently. Good for filtering and ranking.

for doc in candidates:
  p[doc] = Noul(
    "Does this help answer the query?"
  )
return sort(p)
RELATIVE

Which is best?

Choice creates a distribution over the supplied candidates. Something still wins if all are bad.

best = Choice(
  "Which candidate best answers it?",
  candidates
)
MARGINAL UTILITY

What adds new information?

Condition the next decision on already-selected context to reduce redundancy.

while need_more:
  next = Choice(
    state={selected, remaining},
    "Which adds the most NEW info?"
  )

The leadership takeaway

Use generation for creation. Jev for judgment. Code for control.

If its accuracy, calibration, latency and economics hold on real workloads, this is broader than agents: semantic judgments become ordinary building blocks for search, recommendations, routing, prioritization, moderation, UX and automation.

Jev is early access. “Typed output” does not mean the semantic judgment is always correct. Validate it against rules, classifiers, rerankers and LLMs on the workload you care about.

# Instead of asking a chatbot to generate routing JSON:
judgments = jev.ask(state, {
  urgent: Noul("Does this need immediate attention?"),
  owner: Choice(["billing", "identity", "platform"]),
  severity: Score(["routine", "important", "urgent", "critical"])
})

# Ordinary code owns the behavior.
if judgments.urgent > 0.9:
    page(judgments.owner)

Use generation for creation. Jev for judgment. Code for control.
The interesting question is whether Jev preserves enough inference quality at its latency/cost to make semantic judgment cheap enough to put throughout ordinary software.

Jev is early access. TypeSafe reports 70–500ms end-to-end latency, $0.042/M input tokens, parallel typed outputs and Choice cardinality up to 255. Performance claims are primarily TypeSafe's own measurements and should be independently benchmarked for each workload.

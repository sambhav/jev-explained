# Jev Explained

An interactive, leadership-friendly explainer for Jev and the idea of semantic decisions as a software primitive.

## Mental model

- **Noul** → semantic `if`: is X true?
- **Choice** → semantic `switch`: which X?
- **Score** → semantic `sort`: how much X?

The site covers ranking/search, normal product applications, AI/agent compositions, browser use, tool search, safety, routing and evaluation.

## Run locally

Open `index.html` in a browser. The site is self-contained and has no runtime dependencies.

## Publish

This repository is designed to work directly with GitHub Pages from the repository root on `main`.

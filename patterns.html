PATTERN CATALOG

Products built from semantic decisions

The recurring architecture is simple: deterministic systems produce state and constraints → Jev interprets fuzzy meaning → deterministic code acts on the typed result.

SEARCH · SCORE 4–7

Semantic reranking

BM25/vector retrieval gets 20–100 candidates. Jev judges relevance using a small ordered rubric. Code sorts and thresholds.

hits = search(query)
for h in hits:
  h.fit = Score(query + h, relevance_rubric)
return sort(hits)
TOOL SEARCH · SCORE → CHOICE

Find the right capability

Retrieve plausible MCP/tools from thousands, score semantic fit, then make an explicit Choice among a bounded shortlist.

tools = retrieve(goal, top=50)
short = top(score_fit(tools), 10)
tool = Choice(short)
SAFETY · MULTIPLE NOULS

Guardrail before execution

Ask independent questions rather than one vague “safe?” question. Combine probabilities with deterministic policy.

risk = jev.ask(state, {
 injection: Noul(...),
 exfiltration: Noul(...),
 sensitive_action: Noul(...)
})
policy.enforce(risk)
RECOMMENDATIONS · SCORE 4–7

Natural-language preference layer

Keep the recommender/candidate generator. Add semantic ranking for requests like “funny but not stupid, under two hours, okay with parents.”

candidates = recommender(user)
rank(candidates, Score("fit current intent"))
NOTIFICATIONS · NOUL

Is this worth interrupting me?

Combine user context and event semantics, then threshold differently by product surface.

p = Noul("Is this worth interrupting the user now?")
if p > user.threshold: notify()
SUPPORT · CHOICE + SCORE

Route and prioritize

Choice maps meaning to the owning team; Score estimates urgency. SLAs and account tiers remain deterministic inputs.

owner = Choice(teams)
urgency = Score([routine, important, urgent, critical])
INBOX · MULTIPLE NOULS

Semantic properties on ordinary objects

Add “needs reply?”, “waiting on me?”, “time sensitive?” and “contains a decision?” to each message, then build UX on those properties.

E-COMMERCE · SCORE

Fuzzy product requirements

Retrieve using normal search/filtering; rerank against qualities that aren't clean metadata, such as “professional but comfortable for standing all day.”

MARKETPLACE · MULTIPLE NOULS

Listing quality & moderation

Judge misleadingness, scam signals, prohibited content and whether a listing actually matches its category. High-risk outcomes can escalate to specialist systems or humans.

CRM · CHOICE + NOULS

Understand customer intent

Route free-form messages and attach signals such as “asking about pricing?”, “renewal risk?” or “needs technical help?”.

FORMS · NOUL

Semantic validation

Traditional validation answers “is this field populated?”. Jev can answer “does this explanation actually answer what we asked?”.

AGENTS · COMPOSITION

Control loop

Before: injection, intent, risk, tool. During: continue/retry/escalate. After: completed, grounded, policy-compliant. Generation remains separate.

if safe(state):
  tool = choose_tool(state)
  result = execute(tool)
  if not complete(result): retry()

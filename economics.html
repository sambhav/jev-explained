Show the equations and what is included

LLM request cost = (input tokens × input price + output tokens × output price) / 1,000,000

Jev request cost = input tokens × Jev price / 1,000,000

Monthly LLM cost = workflows × (rounds × LLM request cost + shared cost)

Monthly Jev-first cost = workflows × (rounds × (Jev request cost + fallback fraction × LLM request cost) + shared cost)

LLM time = rounds × LLM request time + other time

Expected Jev-first time = rounds × (Jev request time + fallback fraction × LLM request time) + other time

Jev output is priced at zero in this model, following launch pricing. Both paths use the same entered input size. Pricing tiers, cache discounts, batch discounts, different tokenizers, additional retries, throughput limits, human review and the cost of errors are not modeled. Per-request times should include network and service delay. This estimates a mean, not p95; the slowest fallback path can still dominate tail latency.

Price source: TypeSafe’s launch announcement: $0.042 per million input tokens, output free. Checked 18 September 2026. All other defaults are illustrative.

Fallback approaches 100%

You pay for Jev and then the LLM on almost every request. Move the fallback slider to see when the extra call stops paying off.

The rest of the task is slow

If a tool takes 20 seconds, faster model decisions save only the model portion. Try “Slow tools dominate.”

The baseline is already efficient

A fast classifier or short constrained answer may leave much less room to improve. Try “Fast LLM baseline.”

The PM question is: can we deliver more correct outcomes, sooner, at lower total cost? Cheap judgments matter only when they improve that outcome.
